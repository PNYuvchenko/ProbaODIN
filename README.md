# Русский/90 — Django-сайт для подготовки к ЕГЭ по русскому языку

Готовый учебный шаблон с главной страницей, карточками заданий, фильтрацией по темам, поиском, переключением светлой/тёмной темы, страницами заданий, проверкой ответа и разбором.

## Запуск на Windows

1. Распакуй архив и открой папку проекта в VS Code.
2. Создай виртуальное окружение:
   ```bash
   python -m venv venv
   venv\\Scripts\\activate
   ```
3. Установи Django:
   ```bash
   pip install -r requirements.txt
   ```
4. Запусти сервер:
   ```bash
   python manage.py runserver
   ```
5. Открой http://127.0.0.1:8000/

## Где менять содержимое

- `ege/data.py` — задания, ответы, объяснения и темы.
- `templates/ege/home.html` — главная страница.
- `templates/ege/task.html` — страница отдельного задания.
- `static/ege/style.css` — оформление.
- `static/ege/app.js` — поиск, тема и проверка ответов.

## Важно

Задания в проекте — демонстрационные авторские примеры для проверки интерфейса, а не официальный банк ФИПИ и не полный вариант ЕГЭ. Перед использованием в подготовке сверяй формулировки, нумерацию и критерии с актуальными материалами ФИПИ. Перед публикацией замени `SECRET_KEY`, отключи `DEBUG` и настрой `ALLOWED_HOSTS`.
